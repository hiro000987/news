# Cloudflare AI Cards Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development or superpowers:executing-plans to implement task-by-task. Steps use checkbox syntax.

**Goal:** Generate and review Japanese knowledge cards inside the smartphone website without PC or added billing.

**Architecture:** Existing authenticated Worker calls a fixed Cloudflare Workers AI model. D1 stores only a bounded daily operational counter until explicit existing-editor save creates knowledge.

**Tech Stack:** Vanilla JS, Workers AI binding, existing D1/Node tests/Playwright. No new dependency.

**Spec:** `docs/superpowers/specs/2026-10-29-ai-cards-design.md`

## Global Constraints

- Keep Workers Free; no credit purchase, paid model or paid fallback.
- Preserve Google owner authentication, existing records, backup v1 and URL uniqueness.
- AI drafts are unverified and never saved without explicit review.
- No credentials, owner mail or cloud identifiers in source/logs.

## Review Focus

- Concurrent/repeated generation must not exceed the daily app limit.
- Provider errors must preserve regular knowledge/review operations.
- Model output must never supply executable UI or invented source links.
- Logout/account changes during generation must erase/discard private drafts.
- Multiple cards from a source passage must preserve source reference without violating URL uniqueness.
