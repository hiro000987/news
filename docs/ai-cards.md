# AIカード — 2026-10-29

本人はChatGPTからCloudflare上の別モデルへの変更を承認した。PC常駐なしでスマホのサイト内から生成・確認・編集・保存する。

## 利用

ホームまたは知識 → **AIでカード作成** → テーマか元の文章を入力 → 1〜3件を生成 → **この候補を編集** → 内容を確認して **保存する**。

候補は未検証で、自動保存しない。テーマだけでは出典確認・検索・最新情報の取得を行わない。文章は8,000文字まで、テーマは200文字まで。文章モードの本文と答えは原文の抜粋に限定し、サーバーで連続した原文との一致を検査する。文章自体の正しさ、生成された質問やタイトルが適切かは自動保証しない。参考URLは取得せずメモに残す。既存の出典URL一意制約は保持しているため、複数候補の参考URLは出典欄ではなくメモに保持する。

## 接続と費用

- 固定モデル: `@cf/qwen/qwen3-30b-a3b-fp8`。Workerの `ai: { binding: "AI" }` を使用し、AIキーはブラウザーへ渡さない。
- Workers Freeを維持。有料モデル、AI Gateway、前払いクレジット、API課金へのfallbackは使わない。
- Cloudflare全体の無料枠は10,000 Neurons/日で共有。他サービスの利用・混雑により生成できない場合もある。Freeでは無料枠超過はエラーになる。[公式料金](https://developers.cloudflare.com/workers-ai/platform/pricing/)
- アプリ側でも20回/UTC日を原子的に制限。日本時間で毎日9時にリセットし、失敗も回数に含む。自動再試行なし。60秒で応答を打ち切るが、開始済みの推論が後で終了する場合がある。
- 通常の推論内容をモデル学習に使わないことをCloudflareが明記している。[データの扱い](https://developers.cloudflare.com/workers-ai/platform/data-usage/)

## データと保護

既存のGoogle本人認証・Origin検査を経てから生成する。AIへ送るのは生成フォームの入力だけで、登録済み知識を自動収集しない。モデル出力は型・件数・長さ・危険キー・リンクを検査し、HTMLとして挿入しない。入力された参考URLだけを検証してメモへ付加する。日時・モデル・未検証の来歴をサーバーで付与する。

`0002_ai_usage.sql` は運用上の回数テーブルだけを追加する。既存の学習テーブルやデータを削除・変更しない。利用回数は学習データではないため、JSONバックアップv1の対象外。復元でAI利用回数は巻き戻らない。
