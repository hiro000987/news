# AIカード — 現行仕様

Cloudflare Workers AIを使い、テーマまたは文章から学習カードを生成する。現在のフローは生成時にサーバーが自動保存する。過去の手動確認・保存フローの実績は末尾に履歴として分けて記録する。

## 利用

ホームまたは知識 → **AIでカード作成** → テーマか元の文章、生成数（初期値10、選択肢1/3/5/10）、難易度（初級/中級/上級/専門家）を指定 → 生成。

各カードには自由想起問題と3択問題を作成する。生成要求は `/api/ai/generate` が処理し、生成物はサーバーが自動保存する。既存カードは上書きしない。応答の `items` は保存済みカード、`skipped` は既存タイトルとの重複、`failed` は保存に失敗したカード。`generatedCount` は検証に通った生成数、`requestedCount` は要求数で、保存数は `items.length`。レベルは入力 `level` で指定し、サーバーがタイトル末尾・注記・タグに記録する。同じ概念でも別レベルは別カードとして保存できる。

ダイアログを閉じても、開始済みのサーバー生成・保存が続く場合がある。通信エラー時は、先にカード一覧を再読み込みして保存済みデータを確認してから再試行する。失敗要求も回数に含み、アプリ側の上限は20要求/UTC日。

テーマモードでは、初級は基本用語、中級は具体例、上級は状況と制約、専門家は主張と反例を扱う。中級以上の事例部分もAIに必須出力させ、サーバーが問題文に組み込む。難易度や問題の正しさは絶対的に保証しない。

文章モードではカード本文と正答を入力原文からの連続した抜粋とし、サーバーで一致を検査する。難易度は原文で扱われた内容の範囲に合わせる。生成された質問文と誤答選択肢は未検証で、原文の事実性や問題としての適切さを保証しない。テーマだけでは検索・出典確認・最新情報取得を行わない。参考URLは取得せずメモに残す。既存の出典URL一意制約は保持する。テーマは200文字、文章は8,000文字まで。

## 接続と費用

- 固定モデル: `@cf/qwen/qwen3-30b-a3b-fp8`。Workerの `ai: { binding: "AI" }` を使用し、AIキーはブラウザーへ渡さない。
- Workers Freeを維持。有料モデル、AI Gateway、前払いクレジット、API課金へのfallbackは使わない。
- Cloudflare全体の無料枠は10,000 Neurons/日で共有。他サービスの利用・混雑により生成できない場合もある。Freeでは無料枠超過はエラーになる。[公式料金](https://developers.cloudflare.com/workers-ai/platform/pricing/)
- アプリ側でも20要求/UTC日を原子的に制限。日本時間で毎日9時にリセットし、失敗・通信切断も回数に含む。1回の10件生成はアプリ上1要求だが、Workers AIのNeuronsを多く使う。無料枠は10,000 Neurons/日で他利用と共有されるため、10件要求が上限前に失敗する可能性がある。自動再試行なし。60秒で応答を打ち切っても、開始済みの推論・保存が後で完了する場合がある。
- 通常の推論内容をモデル学習に使わないことをCloudflareが明記している。[データの扱い](https://developers.cloudflare.com/workers-ai/platform/data-usage/)

## データと保護

既存のGoogle本人認証・Origin検査を経てから生成する。AIへ送るのは生成フォームの入力だけで、登録済み知識を自動収集しない。モデル出力は型・件数・長さ・危険キー・リンクを検査し、HTMLとして挿入しない。入力された参考URLだけを検証してメモへ付加する。日時・モデル・未検証の来歴をサーバーで付与する。

`0002_ai_usage.sql` は運用上の回数テーブルだけを追加する。既存の学習テーブルやデータを削除・変更しない。利用回数は学習データではないため、JSONバックアップv1の対象外。復元でAI利用回数は巻き戻らない。
